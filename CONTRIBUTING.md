# Guide de contribution - CharleBin


## Workflow de développement

1. Créez une branche depuis `main` avec un nom explicite (ex: fix-bug, feature-name).
2. Effectuez vos modifications en local.
3. Poussez votre branche et ouvrez une Pull Request (PR).

## Règles pour les Pull Requests

* Une PR ne doit traiter qu'un seul sujet à la fois.
* Liez l'Issue concernée dans la description de la PR.
* Nettoyez votre code avant soumission (pas de fichiers de logs ou de dumps).
